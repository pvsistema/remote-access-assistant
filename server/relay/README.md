# Свой сервер связи (ретранслятор)

Передаёт изображение экрана и команды мыши/клавиатуры напрямую между
удалённым компьютером и оператором. Облако при этом только выдаёт пропуска —
картинка через него не идёт.

Подходит для облачного сервера Beget и любого другого VPS с Ubuntu.

## Установка

Нужен домен (например `relay.вашсайт.ру`), указывающий A-записью на IP сервера.
Зайдите на сервер по SSH под root и выполните команду из раздела
**«Свой сервер»** в самой программе — она подставит правильные адреса.

Вручную:

```bash
curl -fsSL https://ВАШ-САЙТ/server/install.sh -o install.sh
RELAY_SOURCE=https://ВАШ-САЙТ/server/relay.py bash install.sh relay.вашсайт.ру
```

Скрипт сам установит Python и nginx, выпустит SSL-сертификат, настроит
автозапуск и в конце покажет **адрес сервера** и **ключ связи**.
Эти две строки нужно вписать в программе на вкладке «Свой сервер».

## Управление

```
systemctl status pv-relay     — состояние
systemctl restart pv-relay    — перезапуск
journalctl -u pv-relay -f     — журнал работы
```

Проверка извне: `https://relay.вашсайт.ру/health`

## Требования к серверу

Минимум 1 ядро и 1 ГБ памяти. Кадры нигде не сохраняются — только
проходят через оперативную память. Для 5–10 одновременных сеансов
хватает самого простого тарифа.

## Безопасность

- Подключиться к сеансу можно только с пропуском, подписанным ключом связи.
- Пропуск действует 6 часов и только для одного сеанса.
- Просмотрщику (режим «только просмотр») сервер не пропускает команды мыши
  и клавиатуры.
- Ключ связи хранится в `/opt/pv-relay/secret.env` и доступен только root.
